Лабораторная работа №4 — Байесовская сеть

Главный файл: lab04.ipynb. Ячейки выполнены, таблицы и графики сохранены.

Запуск:
1. Распакуйте весь архив, сохранив папку data рядом с ноутбуком.
2. Откройте папку lab04 в VS Code или Jupyter.
3. Установите зависимости в выбранное окружение Python:
   python -m pip install -r requirements.txt
4. Откройте lab04.ipynb, выберите это окружение и выполните Run All.
   Рабочая директория — папка lab04.

Проверено на Python 3.13.2. Для просмотра уже сохранённых результатов
повторное выполнение не требуется. Для расчётов интернет не нужен.
Для Jupyter при необходимости отдельно установите jupyterlab.

Состав:
- lab04.ipynb — решение и краткие пояснения;
- data/winequality-white.csv — исходные данные;
- results/ — таблицы результатов и изображения графиков;
- requirements.txt — проверенные версии библиотек;
- CHECKS.txt — результат проверки.
